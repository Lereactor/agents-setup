# Правила проекта Agents

## Документация в PDF — обновлять после каждого релиза в прод

После каждой наработки, которая **реально заработала в проде** (проверена живым
прогоном), обновлять все три PDF в `docs/`:

- `Архитектура-ассистентов.pdf` (генератор `docs/source/architecture.py`);
- `Персональные-ассистенты.pdf` (генератор `docs/source/onepager.py`);
- `Agents-Executive-Report.pdf` (генератор `docs/build-executive-report.py`).

Править исходники-генераторы, пересобирать PDF, проверить рендер страниц
и запушить вместе с изменениями. Пилоты, гипотезы и непроверенные идеи в PDF
не вносить — только то, что работает. Текущее состояние на ноябрь 2026: 9 агентов на своём runner (VPS) +
Kimi K3 через worker-прокси, документы и напоминания, uptime-дежурный,
карты — OpenStreetMap, деплой воркера — GitHub Actions. Время по умолчанию
везде московское: Europe/Moscow, UTC+3 круглый год.

`docs/SETUP-GUIDE.md` — операционная документация: держать в актуальном
состоянии при любых изменениях инфраструктуры, ключей и расписаний.
