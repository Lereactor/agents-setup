# Агент «booking» — поиск жилья посуточно

Дата: 2026-10-07. Routine `Booking` (`trig_01PvQYUmtVhkU2B2WKtaMQxL`).

## Задача
Отели, квартиры, апартаменты, дома, коттеджи, шале, лофты, глэмпинги.
Основная площадка Лева — Суточно.ру, вторая — Островок; плюс Авито
(посуточно) и Туту (отели).

## Поиск MCP / Apify
- MCP у Суточно и Островка нет.
- Apify: для Островка есть `getascraper~ostrovok-hotels-scraper` (рейтинг,
  отзывы, цена за ночь/за срок, бесплатная отмена, завтрак); для Авито —
  `zen-studio~avito-realty-scraper` (`dealType: daily`); для Суточно нет.
- Суточно: внутренний JSON API сайта (найден в бандле веб-приложения):
  - `GET /api/rest/search/getTermSuggestionsWithBoundingBox?query=<город>` →
    `data.suggestions[0].location {id, type}`;
  - `GET /api/json/search/searchObjectsByLocation?locationId&locationType&
    guests_adults&dateBegin&dateEnd&count` (+ `is_house`/`is_apartment`/`is_hotel`);
  - заголовки `api-version: 2.1`, `platform: js`, `token: <публичный токен>`.
  Риск: Суточно может сменить токен — тогда агент напишет «Суточно: не
  ответил», а токен нужно снова достать из `sutochno.ru` (поиск `NH.default`
  в JS-бандле поиска).

## Поведение
1. Не запрос про жильё («отель был ужасный») → skipped, тишина.
2. Параметры: место (обязательно), даты (по умолчанию ближайшие пт→вс),
   гости (2), тип HOTELS/FLATS/HOUSES/ALL, бюджет и пожелания.
3. Параллельный поиск: Суточно всегда, Островок и Туту — для отелей/ALL,
   Авито — для квартир/домов/ALL.
4. Отсев: не вмещает гостей, дороже бюджета, рейтинг <8/10 при 5+ отзывах,
   подозрительно дёшево (<40 % медианы).
5. Ответ (по просьбе Лева «жильё — дело такое»): по каждой площадке топ-3,
   затем 💬 комментарии (сравнение цен площадок и риски), 💡 рекомендация
   (лучший по цене и лучший по качеству), ⓘ. Длиннее 4000 символов — два
   сообщения.

## Маршрутизация в воркере
grocery → booking → travel → shopping. Жильё — по началу слова (`отел`,
`гостиниц`, `хостел`, `апартамент`, `квартир`, `коттедж`, `шале`, `лофт`,
`глэмпинг`, `жиль`, `посуточн`, `суточно`, `переноч`, `островок`); «отель»
убран из travel.

## Стоимость
Apify — бесплатный план ($5/мес), лимит на запуск `maxTotalChargeUsd=0.10`.
Суточно и Туту бесплатно.
