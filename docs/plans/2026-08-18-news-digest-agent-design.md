# Дизайн: агент-новости (Routine)

Дата: 2026-08-18
Статус: готов к настройке в UI (claude.ai/code/routines)

## Контекст

Часть системы из трёх агентов (см. `agents-setup-brief.md`). Это первый агент,
который реально настраивается — самый простой и надёжный (расписание,
без внешних API помимо Telegram).

Telegram-инфраструктура уже готова:
- Бот: `@LAgentsControl_bot`
- Токен: лежит в `tg_api.txt` (в репозитории проекта, не коммитить в общий git)
- Группа: «Lev's assistants», `chat_id = -1004369832565`
- Group joining в BotFather выключен (бота нельзя добавить в новые группы)

## Параметры

- **Расписание**: ежедневно, 08:00 МСК = **05:00 UTC**
- **Темы**: российские банки/банковский сектор + глобальный IT (крупные
  компании, продукты, ИИ, кибербезопасность)
- **Отбор**: до 5 пунктов, агент сам решает сколько реально важного есть
  (может быть меньше 5, если значимых новостей мало)
- **Формат пункта**: 1-2 предложения сути + ссылка на источник
- **Доставка**: `curl` к Telegram Bot API `sendMessage` в конце промпта

## Открытый вопрос при настройке

Токен бота **не** должен быть в открытом виде в промпте. При создании
Routine в UI нужно проверить, есть ли раздел Environment variables/Secrets:
- **Если есть** — положить токен туда под именем `TELEGRAM_BOT_TOKEN`,
  в промпте ссылаться на переменную окружения.
- **Если нет** — придётся вставить токен прямо в текст промпта (менее
  безопасно, но рабочий вариант для одиночного пользователя).

То же самое для `SHEETS_LOG_URL` и `SHEETS_LOG_TOKEN` (см.
`2026-08-18-watchdog-agent-design.md`, шаг 6 промпта) — оба значения
берутся из `sheets_api.txt` (не в git) и кладутся в те же
Environment variables/Secrets Routine.

## Финальный текст промпта для Routine

```
Ты — новостной агент. Раз в день выполни следующее:

1. Через веб-поиск найди главные новости за последние 24 часа по двум темам:
   (a) российские банки и банковский сектор;
   (b) глобальные IT-новости (крупные технологические компании, продукты,
       ИИ, кибербезопасность).

2. Отбери НЕ БОЛЕЕ 5 пунктов суммарно по обеим темам. Не добирай до 5
   искусственно — если реально важного меньше, отправь меньше. Совмещать
   темы необязательно поровну, выбирай по важности.

3. Сформируй сообщение для Telegram в следующем формате:

📰 Новости за {текущая дата в формате ДД.ММ.ГГГГ}

1. {Суть новости в 1-2 предложениях}
   {ссылка на источник}

2. ...

(и так далее, до 5 пунктов)

4. Отправь готовое сообщение в Telegram через Bot API:

   curl -s "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendMessage" \
     -d "chat_id=-1004369832565" \
     --data-urlencode "text@-" <<< "$MESSAGE"

   (если прямая подстановка текста ломает кодировку кириллицы, сначала
   запиши текст сообщения в файл и используй --data-urlencode "text@файл")

5. Если веб-поиск не дал результатов или отправка в Telegram не удалась —
   всё равно отправь в группу короткое сообщение об ошибке с описанием,
   что пошло не так. Не завершай выполнение молча.

6. Залогируй свой запуск для агента-надзирателя (см.
   `2026-08-18-watchdog-agent-design.md`):

   curl -s -L -X POST "${SHEETS_LOG_URL}" \
     -d "token=${SHEETS_LOG_TOKEN}" \
     -d "agent=news-digest" \
     -d "status=success" \
     -d "timestamp=$(date -u +%Y-%m-%dT%H:%M:%SZ)"

   Если шаги 1-4 завершились с ошибкой (см. пункт 5) — залогируй
   `status=error` вместо `success`, но всё равно отправь эту строку
   (даже при сбое надзиратель должен увидеть, что агент запускался).
```
