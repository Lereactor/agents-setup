# Персональные ассистенты: текущая архитектура

Актуально на 19 ноября 2026 года. Здесь описана только работающая production-система; исторические проекты на Claude Code Routines сохранены в `docs/plans/` и в старых разделах `docs/SETUP-GUIDE.md`.

## Что умеет система

В одном Telegram-чате работают 9 LLM-агентов и отдельный дежурный uptime без LLM:

| Агент | Как вызвать | Что делает |
|---|---|---|
| Покупки | «купи…», «найди…», фото товара | Сравнивает Ozon, WB и Я.Маркет через Apify |
| Продукты | «вкусвилл…», «продукты…» | Ищет товары и собирает ссылку на корзину через MCP ВкусВилла |
| Поездки | «поезд…», «самолёт…», «билет…» | Ищет транспорт через Туту MCP и Aviasales |
| Жильё | «отель…», «квартира…», «коттедж…» | Ищет на Суточно, Островке, Авито и Туту; метро и центр — через OpenStreetMap |
| Рядом | «кафе рядом…», геопозиция | Ищет места в OpenStreetMap, показывает адрес, часы и время пешком |
| Документы | файл с отдельным словом «почитай» | Читает PDF, DOCX, TXT, MD, CSV, JSON, HTML и RTF; делает выжимку или отвечает на вопрос |
| Напоминания | «напомни…», «мои напоминания», «отмени напоминание» | Kimi разбирает дату, VPS сохраняет задачу и доставляет её без LLM |
| Новости | автоматически, каждый день в 08:00 по Москве | Дайджест банковских и IT-новостей |
| Надзиратель | автоматически каждые 6 часов, отчёт в 09:00 по Москве | Читает журнал, находит циклы и зависшие запуски, ставит паузу или повторяет запрос |
| Uptime | автоматически каждые 5 минут | Проверяет Worker, Runner и сайт; пишет после двух сбоев подряд и после восстановления |

Несколько задач в одном сообщении разделяются слушателем и выполняются параллельно. Голос распознаёт Whisper в Cloudflare Workers AI. Если ключевых слов нет, но сообщение похоже на просьбу, маршрутизатор Workers AI определяет агента по смыслу.

## Документы и приватность

- Триггер — отдельное слово **«почитай»** в подписи к файлу или в текстовом reply на ранее отправленный файл. Без него файл игнорируется.
- Поддерживаются PDF, DOCX, TXT, MD, CSV, JSON, HTML/HTM и RTF до 10 МБ. Извлекаются первые 100 000 символов. OCR для сканов нет.
- Worker получает файл через Telegram `getFile`, Runner извлекает текст в памяти и передаёт его только в Moonshot/Kimi. Ответ возвращается в исходный Telegram-чат.
- Агент документов имеет только инструменты `log` и `send_reply`: никаких HTTP, MCP и веб-поиска.
- Текст документа и ответ не записываются в Google Sheets. В журнале остаются лишь «Документ получен», «Обработка документа» и итоговый технический статус.
- Напоминания хранятся на VPS в `/var/lib/agents/reminders.json` с правами только для сервисного пользователя. Часовой пояс по умолчанию — Москва, Europe/Moscow UTC+3; доставка — cron каждую минуту.

## Архитектура и расходы

```text
Telegram ↔ Cloudflare Worker ↔ Agents Runner на VPS ↔ внешние API/MCP
                  │                    │
                  ├── Workers AI       ├── Moonshot/Kimi через /llm proxy
                  ├── Telegram files   ├── cron: новости и надзиратель
                  └── KV               ├── cron: напоминания и uptime
                                       └── Google Sheets: технический журнал

GitHub → Actions → Cloudflare Worker
GitHub Pages → сайт «Мои агенты» → Sheets + публичный /status.json
```

- Moonshot/Kimi K3 — оплата за API-токены, отдельно от подписки Kimi Code.
- Apify — расход кредита на скраперы магазинов, Островка и Авито.
- Workers AI — распознавание голоса и резервная маршрутизация в пределах доступной квоты.
- OpenStreetMap/Nominatim, Туту MCP, ВкусВилл MCP, Aviasales MCP, Google Sheets и GitHub Pages — без отдельного LLM-расхода.
- Напоминания после создания и uptime-проверки не вызывают LLM.

## Где лежит код

- `scripts/shopping-listener-worker.js` — Telegram webhook, маршрутизация, документы, Telegram- и LLM-proxy, `/status.json`.
- `scripts/vps/runner-index.js` — канонический исходник `/opt/agents/index.js` на VPS; реестр всех 9 агентов.
- `scripts/vps/prompts/` — сценарии агентов.
- `scripts/vps/document-text.js` — извлечение текста из документов.
- `scripts/vps/reminders-store.js`, `reminders-deliver.js` — хранение и доставка напоминаний.
- `scripts/vps/uptime.js` — дежурный; служебный `RUNNER_HEALTH_URL` задаётся только в серверном env.
- `ai-agent-live/frontend/src/myagents/` — интерактивная схема и история.
- `.kimi-code/mcp.json` — Context7 и DeepWiki для локальной разработки, только чтение.

## Сайт и живой статус

Сайт: https://lereactor.github.io/agents-live/

Публикация из `ai-agent-live/frontend`:

```bash
node scripts/build-site.mjs --deploy
```

Скрипт сохраняет существующий зашифрованный конфиг и пароль. На сайте есть карточки всех агентов, история из Google Sheets и полоса живой инфраструктуры. `/status.json` отдаёт только доступность сервисов, модель, список агентов, паузы и число ожидающих напоминаний — не тексты чатов, документы, ключи или служебные URL.

## MCP для разработки в Kimi Code

- **Context7**: `resolve-library-id` → `query-docs` для актуальной документации библиотеки.
- **DeepWiki**: `read_wiki_structure` → `read_wiki_contents` → `ask_wiki_question` для устройства GitHub-репозитория.
- Серверы подключены глобально и в проекте; разрешены только read-only tools. Проектные документы и ключи им специально не передаются.
- Новые MCP подхватываются в новой сессии Kimi Code. Это инструменты разработчика, а не Telegram-агенты.

## Эксплуатация

Основная инструкция — `docs/SETUP-GUIDE.md`, актуальный релиз — раздел 11. Секреты находятся только в серверном `/etc/agents/runner.env`, секретах Cloudflare/GitHub и локальных файлах из `.gitignore`. Секретные URL и токены не входят в репозиторий, сайт или PDF.
