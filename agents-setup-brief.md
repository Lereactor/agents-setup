# Бриф: система агентов на Claude Code + Telegram

Контекст: пользователь не программист, но готов работать с командной строкой и настройками. Claude Desktop не установлен, работа планируется через Claude Code (CLI) и облачные Routines. Цель — несколько автономных агентов, которые работают самостоятельно (в т.ч. по расписанию/24-7) и присылают отчёты в общую Telegram-группу.

## Нужные агенты

### 1. Агент-покупки (Ozon)
- Работает **по запросу** (не по расписанию), пользователь спрашивает про конкретный товар
- Задача: найти наиболее выгодную цену и оценить отзывы, выдать короткое саммари
- Технический нюанс: у Ozon нет открытого API, сайт блокирует ботов. Два пути:
  - веб-поиск (менее точно, но проще и надёжнее в настройке)
  - браузерная автоматизация через MCP-сервер (например, Playwright MCP), подключённый к Claude Code — точнее, но менее стабильно из-за антибота
- Технически: обычная интерактивная сессия Claude Code, либо Routine с триггером "по API-вызову" (чтобы дёргать из Telegram-бота)

### 2. Агент-новости (банки и IT)
- Работает **раз в сутки** по расписанию — самый простой и надёжный из трёх
- Реализация: Claude Code Routine (claude.ai/code/routines), запуск, например, в 8:00
- Промпт: веб-поиск по темам "банки" и "IT", сжать в 5-7 пунктов самого важного, отправить в Telegram
- Работает штатно на облачной инфраструктуре Anthropic, не требует, чтобы компьютер был включён

### 3. Агент-надзиратель за расходами (токены)
- Задача: следить, эффективно ли команда агентов тратит токены, при необходимости останавливать других агентов и докладывать
- Важное ограничение: агент не видит траты других "магически" — нужен доступ к **Anthropic Usage/Cost API** (уровень организации/админ-ключа, обычно платный тариф с биллингом по использованию)
- Реализация сложнее промпта: нужен скрипт, который периодически опрашивает Usage API, сравнивает с лимитом, шлёт алерт, и умеет через API отключать/останавливать конкретную Routine
- Это не «агент сам решил выключить другого» в человеческом смысле, а API-вызов на основе логики в скрипте

### 4. Агент-заправки (бензин 95, по геоточке) — новая идея, не начата
- Работает **по запросу**: пользователь отправляет в общую Telegram-группу свою геоточку (location)
- Задача: проанализировать сайты https://gdebenz.ru и https://toplivo.tbank.ru, найти ближайшие к присланной точке заправки с бензином АИ-95, выдать короткий ответ (адрес/расстояние/цена, если есть)
- Технический нюанс 1 (триггер): Routines запускаются по расписанию, по API-вызову или по событию GitHub — «прислал геоточку в чат» такого триггера нативно не даёт. Нужен посредник, который слушает Telegram (`getUpdates`/webhook), распознаёт сообщение с location, и уже он дёргает Routine через API-триггер с координатами в параметрах
- Технический нюанс 2 (источники): не проверено, отдают ли gdebenz.ru и toplivo.tbank.ru данные через открытый API или только через веб-страницу (может понадобиться веб-поиск/парсинг вместо структурированного запроса, аналогично проблеме с Ozon)
- Встаёт в очередь после агента-новостей; для реализации сначала нужно разобраться с триггером по геоточке

## Telegram-интеграция
1. Создать бота через @BotFather в Telegram, получить токен
2. Создать группу, добавить туда бота с правом писать сообщения
3. Каждый агент в конце работы делает HTTP-запрос к Telegram Bot API (`sendMessage`) с токеном и ID группы — прописывается как шаг в промпте Routine, Claude Code умеет вызывать curl/API
4. Важно: агенты не ведут между собой "живой" диалог. Реалистичный паттерн — каждый пишет в общую группу с пометкой роли (например "📦 Покупки", "📰 Новости", "⚠️ Надзор"), а агент-надзиратель читает историю группы/логи, а не "слушает" остальных напрямую

## Общая архитектура (варианты для Claude Code)
- **Subagents** — узкоспециализированные помощники внутри одной сессии, определяются в `.claude/agents/*.md`, хороши для задач без нужды в независимом расписании
- **Agent Teams** (экспериментально) — несколько независимых сессий Claude Code, работающих параллельно и общающихся между собой; включается флагом `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`
- **Routines** (research preview) — работают на облачной инфраструктуре Anthropic, по расписанию/по API-вызову/по событию GitHub, продолжают работать даже когда компьютер выключен — подходят для новостного дайджеста и, потенциально, для надзирателя

## Важные предупреждения
- Автономные агенты, работающие круглосуточно, могут расходовать много токенов при нечётком промпте — начинать стоит с одной несложной Routine и следить за расходами первую неделю
- Промпт для Routine должен быть максимально самодостаточным: она выполняется автономно, без права переспросить пользователя, и без запроса разрешений на каждое действие (в отличие от обычной интерактивной сессии)
- Функциональность и лимиты Routines могут меняться, так как это research preview

## Практические шаги для старта (общие)
1. Установить Claude Code: `npm install -g @anthropic-ai/claude-code` (нужен Node.js)
2. В папке проекта: `claude`, затем `/init` для создания CLAUDE.md
3. Описать нужных саб-агентов в `.claude/agents/*.md`
4. Настроить Routine на claude.ai/code/routines: репозиторий/папка, промпт-задание, расписание или триггер
5. Первые запуски проверять вручную (Run now), прежде чем полагаться на автопилот

## Следующий шаг (не сделан в этой сессии)
Пользователь ещё не выбрал, с какого агента начинать конкретную настройку/промпт — предложены варианты: новостной дайджест (проще всего), агент-покупки (Ozon), или сначала настройка Telegram-бота. Решение не принято на момент составления этого брифа.
